# Actuaria+ · Información fiscal (ACTAF-5236 · DIS-HU2)

Prototipo de diseño de alta fidelidad del formulario de **información fiscal de la entidad** en Actuaria+, actualizado (DIS-HU2) para incorporar, manteniendo el lenguaje visual del sistema:

- Campo **País** (por defecto Ecuador)
- Bloque **Agente de retención** — porcentajes de referencia de IR e IVA
- Tres **avisos de validación anti-bloqueo** — entidad suspendida · RUC no vigente · cuenta bancaria de devoluciones
- **Checklist de completitud** en panel glass

Lenguaje visual: sistema **neu · glass · bento** de ActuaFast (superficie `#E8ECF4`, doble sombra neumórfica, glass, navy · indigo · naranja, tipografía Nunito).

**▶ Ver prototipo:** https://renatopuente-ux.github.io/actuariaplus-info-fiscal/

Este diseño es predecesor del desarrollo de **ME-HU1** (campos fiscales), **ME-HU2** (retención) y **ME-HU3** (validaciones). Estado: propuesta para revisión del PM y de un dev del squad *Mis entidades*.
